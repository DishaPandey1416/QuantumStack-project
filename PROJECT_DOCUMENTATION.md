## Main implementation

```text
Spring Boot 3.4.13
Java 17
Spring Data JPA
H2 (default development DB)
MySQL profile
BCrypt
Server-side bearer sessions
HTML/CSS/JavaScript responsive UI
```

1. Authentication
2. Team creation/invitations
3. Project submission
4. Review 0 / Review 1 / Review 2 state machine
5. Faculty/admin approval
6. Explainable recommendation engine
7. Quantum simulator
8. Network simulator
9. History
10. Responsive UI/UX
11. H2 and MySQL deployment options
12. Docker support
